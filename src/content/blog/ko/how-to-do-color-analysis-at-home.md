## 집에서 컬러 분석이 가능할까?

네. 대면 전문 드레이핑이 여전히 골드 스탠더드이지만, 셀프 평가 테스트와 AI 기술을 조합하면 놀랄 만큼 정확한 결과를 집에서 얻을 수 있습니다. 이 가이드는 전 과정을 단계별로 안내합니다.

## 준비물

- 간접 자연광이 들어오는 큰 창문
- 거울
- 흰색, 오프화이트, 실버, 골드 천/종이/의류
- 민낯(메이크업 없음, 안경 제거)
- 스마트폰 카메라
- 선택: 어깨를 감쌀 흰 수건

## 단계 1: 언더톤 판별

언더톤은 컬러 분석의 기초입니다. 나이, 태닝, 체중 변화와 관계없이 변하지 않습니다.

### 혈관 테스트

자연광에서 손목 안쪽 혈관을 봅니다.
- **녹색/올리브 혈관** → 웜 언더톤
- **파란/보라 혈관** → 쿨 언더톤
- **파랑과 녹색 둘 다** → 뉴트럴 언더톤

### 주얼리 테스트

피부 옆에 골드·실버 주얼리를 동시에 대 봅니다.
- **골드가 더 잘 어울림** → 웜 언더톤
- **실버가 더 잘 어울림** → 쿨 언더톤
- **둘 다 비슷하게 좋음** → 뉴트럴 언더톤

### 화이트 vs. 크림 테스트

얼굴 옆에 순백 종이와 크림/아이보리 종이를 대 봅니다.
- **순백이 잘 어울림** → 쿨 언더톤(크림은 칙칙해 보일 수 있음)
- **크림/아이보리가 잘 어울림** → 웜 언더톤(순백은 창백해 보일 수 있음)
- **둘 다 괜찮음** → 뉴트럴 언더톤

### 햇볕 반응 테스트

햇볕에 피부가 보통 어떻게 반응하나요?
- **먼저 타고 골든하게 태닝** → 웜 언더톤
- **쉽게 타고 태닝이 잘 안 되거나 핑크빛** → 쿨 언더톤
- **쉽게 태닝되고 잘 안 탐** → 웜(딥일 가능성)

## 단계 2: 깊이 판별

깊이는 피부·머리·눈을 종합했을 때 전체가 얼마나 밝거나 어두운지를 뜻합니다.

거울 앞에서 평가합니다.
- **라이트:** 밝은 피부 + 금발/밝은 갈색 머리 + 밝은 눈 → 라이트 스프링 또는 라이트 서머
- **딥:** 미디엄~어두운 피부 + 어두운 머리 + 어두운 눈 → 딥 윈터 또는 딥 오텀
- **미디엄:** 그 사이 → 나머지 8시즌 중 하나일 수 있음

## 단계 3: 채도 판별

채도(선명도·채도)는 자연 색감이 얼마나 선명하거나 뮤트한지를 측합니다.

### 밝기(선명도) 테스트

선명한 색(일렉트릭 블루, 핫 핑크)과 같은 hue의 뮤트 버전(더스티 블루, 모브)을 얼굴 옆에 번갈아 대 봅니다.

- **선명한 쪽이 더 좋음** — 클리어/브라이트(브라이트 스프링 또는 브라이트 윈터)
- **뮤트한 쪽이 더 좋음** — 소프트/뮤트(소프트 서머 또는 소프트 오텀)
- **둘 다 압도적이지 않음** — 깊이나 온도가 더 지배적

### 시각적 대비 평가

눈을 가늘게 뜨지 않고 자신을 봅니다.
- **이목구비가 뚜렷히 분리**(밝은 피부에 진한 눈썹, 밝은 눈) → 높은 대비/브라이트
- **이목구비가 부드럽게 어우러짐**(눈썹과 머리 색이 비슷, 은은한 색감) → 낮은 대비/소프트

## 단계 4: DIY 드레이핑 테스트

지금까지 결과를 조합합니다.

### 웜 + 라이트 = 봄

얼굴에 대어 볼 색:
- 피치, 코랄, 웜 그린, 골든 옐로
- 피부가 빛나면 → 봄 타입일 가능성

### 쿨 + 라이트 = 여름

테스트:
- 라벤더, 더스티 로즈, 스카이 블루, 소프트 틸
- 상쾌하고 균형 있어 보이면 → 여름 타입

### 웜 + 딥 = 가을

테스트:
- 러스트, 올리브, 머스타드, 번트 오렌지, 초콜릿
- 풍부하고 안정감 있으면 → 가을 타입

### 쿨 + 딥 = 겨울

테스트:
- 트루 레드, 블랙, 화이트, 로열 블루, 핫 핑크
- 이목구비가 극적으로 살아나면 → 겨울 타입

## 단계 5: 서브 시즌 좁히기

메인 시즌을 알았다면 하위 유형을 정합니다.

**봄인 경우:**
- 라이트 스프링 → 라이트가 가장 두드러짐(파스텔 웜)
- 웜 스프링 → 웜이 가장 두드러짐(골든, 토스티)
- 브라이트 스프링 → 선명도가 가장 두드러짐(비비드, 채도 높음)

**여름인 경우:**
- 라이트 서머 → 라이트(에테리얼, 소프트)
- 쿨 서머 → 쿨(블루 베이스)
- 소프트 서머 → 소프트(블렌디드, 부드러움)

**가을인 경우:**
- 소프트 오텀 → 소프트(뮤트, 어스)
- 웜 오텀 → 웜(골든, 풍부)
- 딥 오텀 → 깊이(강렬, 그라운드)

**겨울인 경우:**
- 딥 윈터 → 깊이(다크, 드라마틱)
- 쿨 윈터 → 쿨(아이시, 블루 베이스)
- 브라이트 윈터 → 선명도(비비드 대비)

## DIY 컬러 분석 흔한 실수

### 실수 1: 조명이 나쁨

실내 인공 조명은 색 캐스트(백열등의 웜 옐로, LED의 쿨 블루)로 모든 테스트를 왜곡합니다. 항상 창가 자연광 — 흐린 날이나 북향이 이상적입니다.

### 실수 2: 메이크업 착용

「미니멀」 메이크업(틴티드 모이스처, 컨실러, 색 있는 립밤)도 색 상호작용을 바꿉니다. 완전 민낯으로 시작하세요.

### 실수 3: 피부색과 언더톤 혼동

매우 어두운 피부도 쿨 언더톤일 수 있고, 매우 밝은 피부도 웜일 수 있습니다. 피부 어두움(깊이)과 언더톤은 독립적입니다.

### 실수 4: 취향으로 결과 왜곡

블랙을 좋아한다고 겨울은 아닙니다. 「멋있어 보이는」 색이 아니라 피부가 건강하고 빛나 보이는 색에 집중하세요.

### 실수 5: 패턴 천으로 테스트

드레이핑에는 솔리드만 사용하세요. 패턴은 여러 색이 섞여 비교를 흐립니다.
