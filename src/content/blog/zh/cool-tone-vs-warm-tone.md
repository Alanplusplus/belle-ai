## 什么是底调？

底调（undertone）是皮肤表面之下的微妙色相。与表面肤色（会因日晒、泛红等变化）不同，底调终生基本不变。

主要有三类底调：

- **冷底调：** 偏粉、偏红或偏蓝的底色
- **暖底调：** 偏黄、偏金或偏桃的底色
- **中性底调：** 冷暖兼有，或没有明显偏向

底调是个人色彩分析中最重要的单一因素，它决定暖色还是冷色在你身上更和谐。

## 为什么底调很重要

穿戴与底调匹配的颜色，会呈现和谐、衬肤的效果：

- **皮肤看起来更通透、更均匀**
- **眼睛显得更亮、更有神**
- **牙齿看起来更白**（没错，真的！）
- **整体更显健康、有活力**

穿戴与底调冲突的颜色，可能让你：

- 显得发灰、蜡黄
- 看起来疲惫、没气色
- 感觉像是「衣服在穿你」，而不是衣服衬托你

## 5 个简单自测方法

### 测试一：血管测试

这是最常见推荐的测试。在自然光下观察手腕内侧的血管。

- **蓝色或紫色血管** → 冷底调
- **绿色血管** → 暖底调
- **蓝绿都有** → 中性底调

**为什么有效：** 血管透过皮肤呈现的颜色，取决于皮肤色素如何过滤光线。冷底调与暖底调皮肤过滤光线的方式不同。

### 测试二：首饰测试

分别试戴银色和金色首饰（或将银色、金色布料贴近脸部），看哪种更衬肤色。

- **银色更好看** → 冷底调
- **金色更好看** → 暖底调
- **两种都好看** → 中性底调

**为什么有效：** 冷金属（银、铂金）与冷底调和谐；暖金属（金、玫瑰金）与暖底调和谐。

### 测试三：白纸测试

在自然光下，将一张纯白纸贴近素颜面部。

- **皮肤显得偏粉或偏红** → 冷底调
- **皮肤显得偏黄或偏金** → 暖底调
- **没有明显冷暖倾向** → 中性底调

**为什么有效：** 纯白纸作为中性背景，让你底下的底调更容易被看出来。

### 测试四：日晒反应测试

回想皮肤在阳光下的反应：

- **容易晒伤，很难晒黑** → 可能是冷底调
- **容易晒黑，很少晒伤** → 可能是暖底调
- **先轻微晒伤，再逐渐晒黑** → 两种都有可能

**重要：** 这项测试不如其他方法可靠，因为日晒敏感度受底调以外很多因素影响。仅作辅助参考，不要当作主要依据。

### 测试五：色布对比测试（披布）

这是最可靠的居家测试。将不同颜色的布料贴近脸部：

**对比同一颜色的冷暖版本：**
- 番茄红（暖）vs 莓果红（冷）
- 橄榄绿（暖）vs 祖母绿（冷）
- 蜜桃色（暖）vs 粉色（冷）

哪种色温让你的皮肤看起来更亮、更均匀，就是你的底调方向。

## 常见底调误区

**误区一：把表面肤色当成底调。** 表面肤色深的人可以是冷底调或暖底调；非常白皙的人也可以是暖底调。

**误区二：以为族裔决定底调。** 每个族裔都有冷、暖、中性底调。东亚肤色常被默认为暖，但很多人其实是冷或中性底调。

**误区三：只测一种方法。** 没有任何单一测试 100% 准确。请用多种方法交叉验证，看结果是否一致。

**误区四：在人造光下测试。** 底调测试务必在自然日光下进行。人造光有自己的色温，会干扰结果。

## 如何运用底调知识

### 化妆
- **粉底：** 匹配底调，而不只是深浅。多数品牌用 W（warm / 暖）、C（cool / 冷）、N（neutral / 中性）标注。
- **唇色：** 冷底调适合浆果、玫瑰木、蓝底红；暖底调适合珊瑚、蜜桃、橘底红。
- **腮红：** 冷 = 粉调；暖 = 蜜桃 / 珊瑚调。

### 衣橱
- **冷底调：** 找蓝基调颜色。藏青、酒红、祖母绿、薰衣草、冷灰。
- **暖底调：** 找黄基调颜色。橄榄、铁锈、芥末、珊瑚、暖棕。
- **中性底调：** 选择空间最大 — 多数颜色都能穿。

### 发色
- **冷：** 灰调、铂金、冷棕、酒红
- **暖：** 金色、铜色、赤褐、焦糖、蜜糖 blonde

## 测试结果仍不确定时

若五种方法都试过仍不确定，你很可能是中性底调 — 这其实是好消息。中性底调在颜色选择上最灵活。

## 常见问题

**底调会变吗？**
不会。底调由皮肤中黑色素与血红蛋白的种类和含量决定，由基因决定。表面肤色会变（晒黑、泛红），但底调保持不变。

**底调与表面肤色（overtone）有什么区别？**
表面肤色是你肉眼看到的表层颜色 — 会受日晒、泛红、痘痘等影响。底调是底下持续存在的微妙色相。

**我是橄榄皮 — 底调是什么？**
橄榄皮带绿色基调，可以是暖橄榄或冷橄榄。绿色 hue 本身与底下的暖 / 冷底调是分开的。很多橄榄皮的人其实是中性或冷底调。
