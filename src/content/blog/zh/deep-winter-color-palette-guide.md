## 什么样的人是深冬型？

深冬型（Deep Winter）位于冷冬型与深秋型之间的色轮位置，是三个冬季亚型中最深的一个。核心特征是**深度** — 深发色、深眼色，以及中等至深度、带冷或中性偏冷底调的皮肤。

**典型深冬型特征：**

- **皮肤：** 中等至深度，带冷（粉 / 蓝）或中性偏冷底调。从瓷白偏蓝底调到深棕偏冷底调都有可能。
- **眼睛：** 深而浓烈 — 深棕、黑棕、深榛色或深冷绿。关键是深度与强度，不一定是具体色相。
- **头发：** 深色 — 通常是深棕到黑色，可能带冷（灰）调。
- **整体对比度：** 高。最深特征（通常是头发 / 眼睛）与最浅特征（皮肤或眼白）之间差异明显。

**关键区分点：** 深冬型与其他冬季型的不同在于 — **深度第一，冷感第二**。你的整体配色先读出「深而浓郁」，再读出「冷而清冽」。

## 深冬型色盘

你的色盘围绕三个原则：**深度、冷感、清晰度**。同时具备这三点的颜色会让你看起来充满活力、气色好。

### 王牌色彩

这些色号会让人忍不住多看一眼：

- **黑色** — 你的终极中性色。与多数季型不同，纯黑真正衬托你，而不是让你显暗沉。
- **酒红 / 牛血红** — 深而冷的红色，呼应你配色的浓郁感。
- **祖母绿** — 深邃的蓝基绿色，能呼应你眼色里的冷绿调。
- **皇室紫** — 浓郁饱和，不是薰衣草或丁香那种淡紫。
- **藏青** — 深而有力，尤其在脸部附近。
- **正红色** — 大胆的蓝基红（经典红唇那一挂）。

### 日常色彩

百搭、始终衬肤：

- 炭灰与深冷灰
- 深青绿（teal）
- 梅紫与深莓色
- 冰白（蓝白，不是奶油白）
- 深巧克力棕（仅限偏冷版本）
- 深橄榄绿（冷调版本，不是偏金橄榄）
- 松绿

### 点缀色彩

用于配饰或小面积单品：

- 洋红与亮粉
- 明亮冷蓝
- 冰薰衣草（少量 — 围巾、首饰）
- 银与铬色

## 深冬型应避开的颜色

这些色会让你看起来疲惫、蜡黄或「不对劲」 — 即使你主观上很喜欢：

- **暖橙、蜜桃、珊瑚** — 与冷底调冲突，皮肤容易显脏、发灰。
- **芥末黄与金黄** — 偏暖、低饱和，与配色需求相反。
- **驼色与暖棕褐** — 在秋季型身上很美，但会让深冬型显得扁平、没精神。
- **粉彩**（尤其是蜜桃、奶油黄等暖粉彩）— 太浅太暖，压不住天然深度。
- **暖棕**（像加太多奶的咖啡）— 换成偏冷的深巧克力或浓缩咖啡棕。
- **低饱和、粉尘色调** — 你需要清晰度；过于灰蒙、柔和的颜色会让你显得暗淡。

**例外：** 若你介于深冬型与深秋型之间（很常见），或许能驾驭一些更暖的色 — 但仍需**深而浓**，而不是浅而暖。

## 深冬型妆容指南

### 粉底与底妆

粉底应匹配冷或中性偏冷底调。选标注「neutral-cool / 中性偏冷」或带粉 / 红底调的粉底。避开「warm / 暖」或「golden / 金」。

### 唇色

深冬型在这里可以玩得最尽兴。你能驾驭其他季型会显得像戏妆的大胆唇色：

- **最佳红：** 蓝调红、经典深红、酒红
- **最佳莓色：** 深覆盆子、黑樱桃、冷梅紫
- **最佳裸色：** 玫瑰木基底裸色、冷调玫瑰木（避开偏桃）
- **大胆选择：** 深牛血红、深莓色，晚宴甚至可试黑樱桃

### 眼妆

- **眼影：** 炭灰、藏青、深紫或森林绿的深烟熏妆，也不会显得「太过」。
- **眼线：** 黑色是好朋友。想柔和些可用深棕或藏青。
- **睫毛膏：** 永远黑色。棕色睫毛膏在深冬型上容易显得没完成感。

### 腮红

冷莓色、深玫瑰、梅紫腮红。避开蜜桃、珊瑚 — 会与底调冲突、不自然。

## 打造深冬型衣橱

### 核心中性色

不要围绕常见但偏暖的「中性色」（米色、驼色、卡其）搭建，而应以这些为主：

- 黑色（终极基础色）
- 藏青
- 炭灰 / 深灰
- 冰白
- 深酒红（对你而言也算中性色）

### 跟趋势又不丢色盘

流行色不断轮换，并非每个流行色都在你的盘里。可以这样调整：

- **粉彩流行时：** 选冰感版本 — 冰蓝、冰薰衣草、冰粉 — 用在有结构的单品，而不是全身粉彩。
- **大地色流行时：** 选最冷、最深的版本 — 深橄榄而非金橄榄，浓缩咖啡棕而非浅棕褐。
- **霓虹流行时：** 优先冷底调亮色（洋红、电光蓝），而非暖霓虹（橙、青柠绿）。

### 首饰与金属

- **银、铂金、白金** — 你的金属。与冷底调和谐。
- **深枪色** — 增加个性，仍在色盘内。
- **玫瑰金** — 若偏冷 / 粉而非偏铜，可作点缀。
- **黄金** — 通常不是最佳；若极少量与银搭配或许可以。若爱金色，选白金或香槟金。

### 配饰

- **包与鞋：** 黑色皮革、深酒红、藏青 — 都是经典深冬。
- **围巾：** 可引入宝石色 — 祖母绿、皇室紫、浆果色。
- **墨镜：** 黑框、深玳瑁（偏冷）、或酒红框。

## 深冬型 vs 其他季型

分型准确很重要 — 穿错季型色盘（哪怕相近）也会略感「不对劲」。

### 深冬型 vs 冷冬型

- **冷冬型**更冷、更冰感。最佳色是明亮、高对比的冰色调（像白雪公主 — 黑发、白皙肤、红唇）。
- **深冬型**更深、更浓郁。你能承载比冷冬型更多的深度，但明亮度略低。
- **测试：** 冰感粉彩让你惊艳 → 可能冷冬型。若冰感粉彩让你显灰，但深宝石色让你发光 → 深冬型。

### 深冬型 vs 深秋型

- **深秋型**更暖。深色偏橄榄、琥珀、铁锈，而非冷色。
- **深冬型**更冷。深色偏藏青、炭灰、冷酒红。
- **测试：** 铁锈橙衬衫贴脸 vs 冷酒红。铁锈让皮肤更有生气 → 深秋型。酒红让你发光 → 深冬型。

## 速查表

| 类别 | 最佳选择 | 避免 |
|----------|-------------|-------|
| 中性色 | 黑、藏青、炭灰、冰白 | 米色、驼色、卡其、奶油白 |
| 红色 | 蓝调红、深红、酒红、葡萄酒红 | 橘红、番茄红、珊瑚 |
| 绿色 | 祖母绿、松绿、深青绿 | 橄榄、鼠尾草、青柠、薄荷 |
| 蓝色 | 藏青、皇家蓝、深青绿 | 浅蓝、长春花蓝 |
| 紫色 | 皇室紫、梅紫、深浆果 | 大面积薰衣草、丁香、灰紫 |
| 金属 | 银、铂金、白金 | 黄金、黄铜、铜 |
| 唇色 | 浆果、葡萄酒红、蓝调红、冷裸 | 蜜桃、珊瑚、暖裸 |

## 不确定是不是深冬型？

色彩分析容易让人困惑 — 光线、周围颜色、甚至心情都会影响你对自己配色的感知。传统披布（色布贴脸）需要训练有素的眼睛与可控光线。

若怀疑自己是深冬型，先测核心原则：**深、冷、高对比的颜色是否让皮肤更清晰、眼睛更亮？** 若是，你很可能属于冬季型 — 天然配色的深度会告诉你是深冬、冷冬还是亮冬。
