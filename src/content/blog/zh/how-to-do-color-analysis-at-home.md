## 可以在家做色彩分析吗？

可以。虽然面对面专业披布仍是金标准，你可以在家结合自评测试与 AI 技术，获得非常准确的结果。本指南会一步步带你走完整个流程。

## 你需要准备什么

- 一扇有间接自然日光的大窗户
- 镜子
- 白色、米白、银色和金色的面料/纸张/衣物
- 素颜（卸妆，摘下眼镜）
- 手机相机
- 可选：白色毛巾围在肩上

## 步骤 1：确定你的底调

底调是色彩分析的基础。它不会随年龄、晒黑或体重变化而改变。

### 血管测试

在自然光下看手腕内侧的血管：
- **绿色/橄榄色血管** → 暖底调
- **蓝色/紫色血管** → 冷底调
- **蓝绿都有** → 中性底调

### 首饰测试

把金色和银色首饰并排贴在皮肤上：
- **金色更好看** → 暖底调
- **银色更好看** → 冷底调
- **两者同样好看** → 中性底调

### 纯白 vs 米白测试

把纯白纸和奶油/象牙纸并排贴在脸旁：
- **纯白更衬** → 冷底调（米白会让你显蜡黄）
- **奶油/象牙更衬** → 暖底调（纯白会让你显没精神）
- **两者都可以** → 中性底调

### 日晒反应测试

皮肤晒太阳通常如何反应？
- **先晒红再晒成金色** → 暖底调
- **容易晒伤，难晒黑或偏粉** → 冷底调
- **容易晒黑，很少晒伤** → 暖（可能偏深）

## 步骤 2：确定你的深度

深度指整体配色的深浅——要同时看皮肤、头发和眼睛。

站在镜前评估：
- **浅：** 白皙皮肤 + 金发/浅棕发 + 浅色眼睛 → 浅春型或浅夏型
- **深：** 中深到深肤色 + 深色发 + 深色眼 → 深冬型或深秋型
- **中等：** 介于两者之间 → 可能是其余 8 个季型中的任意一种

## 步骤 3：确定你的彩度

彩度（也称清晰度或饱和度）衡量自然配色有多鲜明或多柔和。

### 明亮度测试

把一种鲜艳色（如电光蓝或亮粉）和同一色相的低饱和版（灰蓝或灰紫）并排贴在脸旁：

- **鲜艳更好看** — 你属于清晰/明亮型（亮春型或亮冬型）
- **柔和更好看** — 你属于柔和/低饱和型（柔夏型或柔秋型）
- **两者难分高下** — 深度或冷暖是你更突出的特征

### 视觉对比度评估

不眯眼看自己：
- **五官清晰分离**（浅肤上的深眉、明亮的眼）→ 高对比/明亮型
- **五官柔和融合**（眉色接近发、配色低调）→ 低对比/柔和型

## 步骤 4：DIY 披布测试

现在综合前面的结论：

### 暖 + 浅 = 春季型

在脸旁试这些颜色：
- 桃色、珊瑚、暖绿、金黄
- 若让皮肤发光 → 你很可能是春季型

### 冷 + 浅 = 夏季型

试：
- 薰衣草、灰玫瑰、天蓝、柔青绿
- 若让你看起来清新、气色均衡 → 夏季型

### 暖 + 深 = 秋季型

试：
- 铁锈、橄榄、芥末、焦橙、巧克力
- 若感觉浓郁、稳重 → 秋季型

### 冷 + 深 = 冬季型

试：
- 正红、黑、白、宝蓝、亮粉
- 若让五官一下子鲜明突出 → 冬季型

## 步骤 5：缩小到子季型

确定主季型后，判断具体子类型：

**若是春季型：**
- 浅春型 → 浅色最突出（偏暖的粉彩）
- 暖春型 → 暖感最突出（金色、烤面包般的暖）
- 亮春型 → 清晰度最突出（鲜明、饱和）

**若是夏季型：**
- 浅夏型 → 浅色最突出（轻盈、柔和）
- 冷夏型 → 冷感最突出（偏蓝）
- 柔夏型 → 柔和最突出（融合、温柔）

**若是秋季型：**
- 柔秋型 → 柔和最突出（低饱和、大地色）
- 暖秋型 → 暖感最突出（金色、浓郁）
- 深秋型 → 深度最突出（强烈、沉稳）

**若是冬季型：**
- 深冬型 → 深度最突出（深、戏剧感）
- 冷冬型 → 冷感最突出（冰感、偏蓝）
- 亮冬型 → 清晰度最突出（鲜明对比）

## DIY 色彩分析常见错误

### 错误 1：光线不对

室内人造光有色偏（白炽灯偏暖黄、LED 偏冷蓝），会扭曲每一次测试。务必用窗户的自然日光——阴天或朝北最理想。

### 错误 2：带妆测试

即便「极简」妆（有色保湿、遮瑕、有色润唇膏）也会改变颜色与皮肤的互动。请完全素颜开始。

### 错误 3：混淆肤色深浅与底调

深肤色可以有冷底调，浅肤色可以有暖底调。肤色深浅（深度）与底调是独立维度。

### 错误 4：让喜好影响结果

你可能爱穿黑，但不代表你是冬季型。关注什么让皮肤看起来健康有光，而不是什么你觉得「酷」。

### 错误 5：用有图案的面料测试

披布时只用纯色。图案含多种颜色，会搅乱对比。
