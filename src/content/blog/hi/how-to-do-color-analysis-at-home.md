## क्या घर पर रंग विश्लेषण हो सकता है?

हाँ। Professional draping gold standard है, लेकिन self-assessment tests और AI से remarkably accurate results मिल सकते हैं।

## क्या चाहिए

- बड़ी खिड़की, indirect daylight
- दर्पण
- सफ़ेद, cream, silver, gold fabric
- bare face
- phone camera

## चरण 1: अंडरटोन

### Vein Test
- **हरी/olive नसें** → गर्म
- **नीली/बैंगनी** → ठंडा
- **दोनों** → तटस्थ

### Jewelry Test
- **सोना बेहतर** → गर्म
- **चांदी बेहतर** → ठंडा
- **दोनों** → तटस्थ

### White vs Cream Test
- **Pure white flattering** → ठंडा
- **Cream flattering** → गर्म

## चरण 2: गहराई

- **हल्का:** fair skin + light hair + light eyes → Spring/Summer
- **गहरा:** medium-dark skin + dark hair + dark eyes → Autumn/Winter

## चरण 3: क्रोमा

Bright color (electric blue) vs muted (dusty blue) test:
- **Bright बेहतर** → Bright Spring/Winter
- **Muted बेहतर** → Soft Summer/Autumn

## चरण 4: DIY Draping

- **गर्म + हल्का = Spring:** peach, coral, warm green
- **ठंडा + हल्का = Summer:** lavender, dusty rose, sky blue
- **गर्म + गहरा = Autumn:** rust, olive, mustard
- **ठंडा + गहरा = Winter:** true red, black, royal blue

## Common Mistakes

1. **Bad lighting** — daylight only
2. **Makeup** — even minimal changes results
3. **Skin color vs undertone confuse**
4. **Preferences bias**
5. **Patterned fabric** — solid colors only
