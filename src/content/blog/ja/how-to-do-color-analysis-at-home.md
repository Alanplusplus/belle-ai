## 自宅でカラー分析はできる？

はい、できます。対面でのプロのドレーピングがゴールドスタンダードではありますが、セルフ評価テストとAI技術を組み合わせれば、自宅でも驚くほど正確な結果を得られます。このガイドでは、プロセス全体をステップごとに説明します。

## 必要なもの

- 間接的な自然光が入る大きな窓
- 鏡
- 白、オフホワイト、シルバー、ゴールドの布／紙／衣類
- すっぴん（メイクなし、メガネを外す）
- スマホのカメラ
- 任意：肩に巻く白いタオル

## ステップ1：アンダートーンを判定する

アンダートーンはカラー分析の土台です。年齢、日焼け、体重の変動では変わりません。

### 血管テスト

自然光の下で、手首の内側の血管を見てください。
- **グリーン／オリーブの血管** → ウォームアンダートーン（イエベ）
- **ブルー／パープルの血管** → クールアンダートーン（ブルベ）
- **ブルーとグリーン両方** → ニュートラルアンダートーン

### ジュエリーテスト

ゴールドとシルバーのジュエリーを肌の横に当てて比べます。
- **ゴールドの方が似合う** → ウォームアンダートーン
- **シルバーの方が似合う** → クールアンダートーン
- **どちらも同程度似合う** → ニュートラルアンダートーン

### ホワイト vs クリームテスト

純白の紙とクリーム／アイボリーの紙を顔の横に当てます。
- **純白が似合う** → クールアンダートーン（クリームは顔をくすんで見せる）
- **クリーム／アイボリーが似合う** → ウォームアンダートーン（白は顔を疲れて見せる）
- **どちらもOK** → ニュートラルアンダートーン

### 日焼け反応テスト

日焼けに対して肌は通常どう反応しますか？
- **先に焼けてからゴールデンに日焼け** → ウォームアンダートーン
- **焼けやすく、日焼けしにくいかピンクになる** → クールアンダートーン
- **日焼けしやすく、ほとんど焼けない** → ウォーム（おそらくディープ）

## ステップ2：深さ（デプス）を判定する

深さとは、肌・髪・目を合わせた全体の色合いがどれだけ明るいか暗いかを指します。

鏡の前に立ち、次を評価します。
- **ライト：** 色白＋ブロンド／ライトブラウンの髪＋明るい目 → ライトスプリングまたはライトサマー
- **ディープ：** 中〜暗い肌＋暗い髪＋暗い目 → ディープウィンターまたはディープオータム
- **ミディアム：** その中間 → 残り8シーズンのいずれかの可能性

## ステップ3：彩度（クロマ）を判定する

彩度（クリアさや彩度とも）は、自然な色合いがどれだけ鮮やかか、くすんでいるかを測ります。

### 明るさテスト

鮮やかな色（エレクトリックブルーやホットピンクなど）を顔の横に当て、同系色のくすんだ版（ダスティブルーやモーブ）と比べます。

- **鮮やかな方が似合う** — クリア／ブライト（ブライトスプリングまたはブライトウィンター）
- **くすんだ方が似合う** — ソフト／ミュート（ソフトサマーまたはソフトオータム）
- **どちらも優位でない** — 深さか温度感が支配的な特性

### 視覚的コントラストの評価

目を細めずに自分を見てください。
- **パーツがはっきり分離している**（明るい肌に対する暗い眉、鮮やかな目）→ ハイコントラスト／ブライト
- **パーツがやわらかく溶け合う**（眉が髪に近い、控えめな色合い）→ ローコントラスト／ソフト

## ステップ4：DIYドレーピングテスト

ここまでの結果を組み合わせます。

### ウォーム＋ライト＝スプリング

次の色を顔に当ててテスト：
- ピーチ、コーラル、ウォームグリーン、ゴールデンイエロー
- 肌が輝くように見える → スプリングタイプの可能性が高い

### クール＋ライト＝サマー

テストする色：
- ラベンダー、ダスティローズ、スカイブルー、ソフトティール
- フレッシュでバランスよく見える → サマータイプ

### ウォーム＋ディープ＝オータム

テストする色：
- ラスト、オリーブ、マスタード、バーントオレンジ、チョコレート
- リッチで地に足のついた感じ → オータムタイプ

### クール＋ディープ＝ウィンター

テストする色：
- トゥルーレッド、ブラック、ホワイト、ロイヤルブルー、ホットピンク
- パーツが劇的に際立つ → ウィンタータイプ

## ステップ5：サブシーズンに絞り込む

メインシーズンが分かったら、どのサブタイプかを判定します。

**スプリングの場合：**
- ライトスプリング → 明るさが最も目立つ（パステルのウォーム）
- ウォームスプリング → 暖かさが最も目立つ（ゴールデン、トースト感）
- ブライトスプリング → クリアさが最も目立つ（鮮やか、彩度高め）

**サマーの場合：**
- ライトサマー → 明るさが最も目立つ（エーテル、ソフト）
- クールサマー → クールさが最も目立つ（ブルーベース）
- ソフトサマー → ソフトさが最も目立つ（ブレンド、やさしい）

**オータムの場合：**
- ソフトオータム → ソフトさが最も目立つ（くすみ、アーシー）
- ウォームオータム → 暖かさが最も目立つ（ゴールデン、リッチ）
- ディープオータム → 深さが最も目立つ（強烈、地に足のついた）

**ウィンターの場合：**
- ディープウィンター → 深さが最も目立つ（ダーク、ドラマチック）
- クールウィンター → クールさが最も目立つ（アイス、ブルーベース）
- ブライトウィンター → クリアさが最も目立つ（鮮やかなコントラスト）

## DIYカラー分析でよくある間違い

### 間違い1：照明が悪い

室内の人工照明には色かぶり（白熱灯のウォームイエロー、LEDのクールブルー）があり、すべてのテストを歪めます。必ず窓からの自然光を使い——できれば曇りの日か北向きが理想です。

### 間違い2：メイクをしたまま

「最小限」のメイク（ティンティドモイスチャライザー、コンシーラー、色付きリップ balm）でも、色と肌の相互作用を変えます。完全なすっぴんから始めましょう。

### 間違い3：肌の色とアンダートーンを混同

非常に暗い肌でもクールアンダートーンがあり、非常に色白でもウォームアンダートーンがあります。肌の明暗（深さ）とアンダートーンは独立した次元です。

### 間違い4：好みで結果を歪める

黒が好きでも、ウィンターとは限りません。自分が「かっこいい」と思う色ではなく、肌を健康的で輝いて見せる色に集中してください。

### 間違い5：柄物の布でテスト

ドレーピングは無地のみ使いましょう。柄には複数の色が含まれ、比較を曇らせます。
